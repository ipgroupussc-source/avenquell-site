What has to be true

The frames are built around the product in your photograph, so the photograph decides how far they can go. One clear shot of the actual product is enough; a screenshot of a screenshot is not.

You upload the photo on the order page before paying, so you can see it arrived. The day is counted from the point the order and the photo are both in.

If accuracy of label copy, texture or exact colour is critical, say so in the order — that changes what references we need and we will tell you before producing anything.
